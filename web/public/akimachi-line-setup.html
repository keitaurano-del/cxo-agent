LINE連携 設定手順（Keita操作分）

合計 約15〜20分。STEP 5 まで終えたら、あとは Son が開通まで実施します。

約3分STEP 1｜LINEビジネスID を作る
account.line.biz/login →「LINEアカウントで続ける」→ 案内に沿って登録（名前は屋号でOK）
約5分STEP 2｜LINE公式アカウントを作る
manager.line.biz →「作成」→ アカウント名 空き待ちウォッチ・業種を入力して作成
約3分STEP 3｜Messaging API を有効化
公式アカウント管理画面 → 右上「設定」→「Messaging API」→「利用する」→ プロバイダーは新規作成（名前は任意）
約5分STEP 4｜トークン2つを発行
developers.line.biz/console → 作ったチャネルを開く
1. 「Messaging API設定」タブ最下部 → チャネルアクセストークン（長期）を発行してコピー
2. 「チャネル基本設定」タブ → チャネルシークレットをコピー
約1分STEP 5｜トークン2つを Son のチャットに貼る
以降は Son が実施（約10分）: .env設置 → 再起動 → Webhook URL設定（https://akimachiwatch.com/api/line/webhook ほか各サイト）→ 疎通テスト → サイトの「準備中」表記解除 → マイページのLINE連携カード開通

ユーザー側の使い方（開通後）: 公式アカウントを友だち追加 → マイページに表示される連携コードをLINEで送信 → 以降の空き通知がLINEに届く（不達時はメールに自動フォールバック）。正本: akimachiwatch/docs/LINE-SETUP.md
