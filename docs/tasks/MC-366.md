# MC-366: bilibiliサムネ表示崩れ修正

- **起票**: 2026-08-03 21:44 Keita スクショ報告（ClipItNow 解析ページで bilibili 動画のプレビューサムネが真っ黒）
- **担当**: Son / **状態**: DONE（2026-08-03）

## 原因

yt-dlp が返す bilibili サムネURL（i0.hdslb.com）が二重に表示不可:
1. `http://` で返る → https サイト上で mixed content ブロック
2. https に直しても Referer: clipitnow.net 付きだと **403**（ホットリンク保護）。Referer 無しなら 200

ランキングのシードサムネは `/thumbs/` ローカルキャッシュ済みのため無事。壊れるのは解析(/api/info)後の詳細画面のみ。

## 対応

video-dl `server.py`（commit 3c2c6c8・リモート無しローカルリポジトリ）:
- `norm_thumbnail()`: probe 結果のサムネを http→https 正規化し、`THUMB_PROXY_HOSTS`（*.hdslb.com）該当は `/api/thumb?u=...` へ書き換え
- `GET /api/thumb`: Referer 無しで取得→ `thumbs/px-<md5>.<ext>` にキャッシュ→ image/* 配信（max-age=86400）。ホスト allowlist で SSRF 防止、Content-Type 検査、2MB 上限、tmp→rename の原子的書き込み
