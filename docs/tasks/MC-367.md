## 構想（設計）

Apollo上でLBO（レバレッジド・バイアウト）モデルを組める機能。Zaimu.ai時代の「動くモック→反復改善」方式で進める。

### フェーズ案

- **P1（済）**: 単一静的HTMLの対話モック `web/public/lbo-mockup.html`
  - 前提入力14項目（EBITDA/買収・売却マルチプル/シニア・メザニン構成/金利/強制返済/成長率/D&A/Capex/税率/保有年数/費用）
  - 自動計算: Sources & Uses → 予測PL/FCF → デットスケジュール（強制返済＋キャッシュスイープ）→ IRR/MOIC → バリュークリエイション3分解（EBITDA成長/マルチプル/デレバレッジ）→ IRR感応度表（売却x×負債x）
  - 解説ボックス＋用語辞書（Zaimu.aiで好評だった「読み方」注釈スタイル・AI演出なし・ライト基調）
- **P2（案・要Keita）**: 実企業データ連携 — EDINET/決算短信からEBITDA等を取込み（Zaimu.aiの部品知見を流用）
- **P3（案・要Keita）**: シナリオ保存・比較、Excel/CSVエクスポート、Apolloサイドメニュー常設化（App.tsxはMC-290系の共有ツリー事情に注意）
- **P4（案）**: AI講師モード — 前提の妥当性コメント、案件別の論点解説

### 簡易モデルの割り切り（P1）

運転資本増減省略・中間配当なし・売却費用考慮外・現金不足時は簡易取り崩し。IRRは中間CFなし前提の MOIC^(1/N)-1。
