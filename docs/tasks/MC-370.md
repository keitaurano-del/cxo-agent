## 1. 需要分析（要点）

**最大の発見: Classic Pro（56畳・10万円級）クラスのレンタルはほぼ空白地帯。**

- Rentio の Blueair 取扱は Blue Max/Signature/Protect のみ。Classic Pro のレンタルは大手に無い。
- 大手2社が撤退済み（kikito 2026/6終了・DMMいろいろレンタル 2023終了）→ 競合減少中。
- 花粉症有病率 42.5%。需要は**二峰性**: 2〜4月（花粉・黄砂）と11〜12月（乾燥・ウイルス）。8月が底。
- 有望セグメント: ①重症花粉症（3〜4ヶ月だけ・許容 3-6千円/月） ②出産家庭（〜1歳・2-4千円） ③ペット多頭飼い（通年化しやすい・4-7千円＋購入転換） ④法人小口=クリニック/保育園/店舗（通年・5-15千円・夏の稼働率の底荷に最適）。
- レンタル相場: 高級機は**本体価格の5〜9%/月**。Rentio Protect 7410i（10万円級）=8,600円/月が直接の参照点。

### 在庫リスクの織り込み（v2 価格の根拠）

- v1 のシーズン8,980円は法人通年契約を夏の底荷にする前提で、法人なしでは遊休リスクを賄えなかった → 再設計。
- **シーズン機は年2回転・稼働率50%を前提に置く**。1回転の限界利益 ≒ 29,940 −（送料6,000＋整備1,000＋フィルター6,000＋決済1,100）≒ 1.6万円。年2回転 3.2万円/台 → 中古仕入4.3万円を約1.4年で回収。**夏に全く貸せなくても成立する**。
- **v1 の「12ヶ月で実売価格に全額充当」は原価割れのため廃止**（受取95,760 < 本体7万＋フィルター2.1万＋送料・決済1万）。v2 の買取条件は **新品定価108,900円基準・既払レンタル料は全額充当・いつでも買取可**（8/8 Keita「最初は新品の価格でいい」）: 買取成立時の受取総額108,900 − 原価計約7.4万（中古仕入時）≒ 約3.5万円黒字で出口も確保。
- **資本の逐次投入**: 増台は繁忙期直前（12-1月）のみ・予約が入ってから仕入れる。夏前増台はしない。
- **下方リスク限定**: 中古美品仕入れなら売却出口が中古相場約4万円にあり、撤退時毀損は台あたり数千円〜1万円。
- **夏の遊休対策（法人なし版）**: 6-8月はスタンダード限定オフシーズン割（例5,980円）＋梅雨カビ・ハウスダスト訴求。埋まらない在庫は整備・SEO仕込みに充当。
