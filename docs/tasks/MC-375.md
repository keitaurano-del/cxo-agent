# MC-375 — Kimi 専用ターミナル追加

Keita 依頼（2026-08-18）「kimi ai 使えるようにして。専用ターミナル作って」。

## 成果物の場所

### ① OpenClaw エージェント層
- `~/.openclaw/openclaw.json`
  - `env.MOONSHOT_API_KEY`（git 管理外・mode 0600 に隔離）
  - `models.providers.moonshot`（baseUrl `https://api.moonshot.ai/v1`・openai-completions・kimi-k2.6/k2.5/k2-thinking 登録）
  - `agents.defaults.models` に `moonshot/kimi-k2.6`(alias `kimi`) ほか
  - `agents.list` に id `kimi`（既定 `moonshot/kimi-k2.6`・workspace `~/.openclaw/workspace-kimi`）
  - バックアップ: `openclaw.json.son-bak-pre-kimi-20260818`

### ② Apollo タイル層
- `~/cron-scripts/term6-openclaw-kimi.sh`（tmux `openclaw-kimi` → `openclaw chat --session agent:kimi:main`）
- `/etc/systemd/system/apollo-terminal-6.service`（ttyd 127.0.0.1:7686・enabled）
- `cxo-agent/server/src/config.ts` TERMINALS に id:6/port:7686/label`Kimi`/tmux`openclaw-kimi`
- `cxo-agent/web/src/views/Terminal.tsx` TERMINAL_TABS/DEFAULT_TERMINAL_LABELS に id:6 追加
- `web/dist` 再ビルド済（`/terminal/6/`・`Kimi` 焼込み確認）

## 検証方法と結果
- OpenClaw 疎通: 隔離 config で `KIMI_LIVE_OK` 成功→本番 config で `openclaw agent --agent kimi` が実応答（「私は Kimi（Kimi K2.6）です」）。
- ttyd: `curl -u apollo:*** http://127.0.0.1:7686/` → 200（無認証 401）。既存 term5(7685) と同挙動。
- proxy: `/terminal/6/` は Apollo 認証層で 401（ルート存在＝配線OK）。
- dist: `web/dist/assets/Terminal-*.js` に `/terminal/6/` と `Kimi` 焼込み確認。
- サービス: `apollo-terminal-6.service` active/enabled、`mission-control.service` active。

## 本番反映有無
- 反映済み（この箱）。openclaw hot reload＋apollo-terminal-6 起動＋mission-control 再起動で稼働。
- タイルは Apollo 画面のターミナル群に「Kimi」として表示。初回クリックで tmux `openclaw-kimi` が生成され Kimi に接続。

- moonshot は従量課金（K2.6: 入力$0.95・出力$4.0/MTok）。残高切れで 429（suspended）。platform.moonshot.ai で要チャージ監視。
