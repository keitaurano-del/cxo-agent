## 推定月間収益 Base 上位15（根拠つき）

### 1. 複利/NISA積立シミュレータ — Low ¥0.8万 / **Base ¥3.5万** / High ¥18万
- **ボリューム根拠**: 「複利 計算」数千〜3万＋「積立 シミュレーション」「NISA シミュレーション」で計数万〜10万規模。新NISA以降の構造的成長KW群
- **なぜCPC高い**: 証券会社・ロボアド・銀行が口座開設1件数千〜1万円のCPAで出稿（CPC 300〜1,000円）
- **到達PV前提**: 「月3万 30年 複利」等の組合せ静的ページ数百枚でロングテール獲得CTR 3〜5%×回遊1.5
- **立ち上げ**: 6〜10ヶ月 / **作りやすさ**: ◎1日（client完結・グラフのみ）
- **リスク**: 証券公式がビッグKW上位。→ロングテール＋取り崩し(FIRE)モードの空白で刺す
- **総評: 収益×作りやすさ×AI耐性の三冠。全案の筆頭で変わらず**

### 2. ふるさと納税 上限額計算 🆕 — Low ¥0.7万 / **Base ¥3.5万** / High ¥20万
- **ボリューム根拠**: 「ふるさと納税 上限」「シミュレーション」クラスタ月10万規模、11〜12月は数十万に爆発（Geminiクロスチェックでも5万〜15万）
- **なぜCPC高い**: 楽天ふるさと納税・さとふる・ふるなび等ポータルの獲得競争（CPC 200〜600円）＋アフィ併用可
- **到達PV前提**: 「年収◯万 家族構成△ 上限」組合せページ量産。年末スパイクで獲得CTR 3〜6%
- **立ち上げ**: 6ヶ月（**今から作れば11月商戦に間に合う**） / **作りやすさ**: ○1〜2日（住民税所得割の概算ロジック）
- **リスク**: 季節偏重（収益の6割が10〜12月）・ポータル自身のシミュレータが競合
- **総評: 新規案の最有力。手取り計算と部品共有で2本目コストが極小**

### 3. 住宅ローン計算機 — Low ¥0.6万 / **Base ¥3.0万** / High ¥18万
- **ボリューム根拠**: 「住宅ローン シミュレーション」3万〜10万＋関連（月々/繰上/借入可能額）で10万規模
- **なぜCPC高い**: 銀行・モーゲージ・借換サービスが1顧客LTV数十万円で出稿（CPC 300〜1,000円）
- **到達PV前提**: 「3000万 35年 金利1.5%」等の組合せページでロングテールCTR 2〜4%
- **リスク**: 銀行公式・SUUMO等が上位占拠=ビッグKWは獲れない前提で設計
- **立ち上げ**: 8〜12ヶ月 / **作りやすさ**: ◎1日（#1と部品共有）

### 4. 手取り/税金計算 — Low ¥0.6万 / **Base ¥2.8万** / High ¥15万
- **ボリューム根拠**: 「手取り 計算」5万〜15万（Gemini整合）＋「年収◯◯万 手取り」ロングテール群で数十万規模
- **なぜCPC高い**: 転職エージェント・副業/節税サービス（CPC 200〜600円）
- **到達PV前提**: 年収別静的ページ×毎年の料率更新で資産化。獲得CTR 2〜4%
- **リスク**: 強豪個人サイト既存。料率の年次更新を怠ると即死
- **立ち上げ**: 8〜12ヶ月 / **作りやすさ**: ○2日（社保・税ロジック）

### 5. 退職金・失業給付シミュレータ — Low ¥0.5万 / **Base ¥2.5万** / High ¥12万
- **ボリューム根拠**: 「失業保険 いくら」3万〜10万（Gemini整合）＋退職金税金・待期期間KW群
- **なぜCPC高い**: 転職エージェント・退職代行・保険（CPC 200〜600円）。退職検討者=転職広告の最優良ターゲット
- **到達PV前提**: 自己都合/会社都合×年齢×勤続の分岐ページ。CTR 2〜4%
- **リスク**: 制度改定追従が必須（それが参入障壁でもある）
- **立ち上げ**: 8〜12ヶ月 / **作りやすさ**: ○2日

### 6. 年金受給額シミュレータ 🆕 — Low ¥0.5万 / **Base ¥2.2万** / High ¥10万
- **ボリューム根拠**: 「年金 いくら もらえる」「厚生年金 計算」で10万規模。高齢化で構造的成長
- **なぜCPC高い**: 保険・iDeCo・資産運用相談（CPC 200〜500円）。老後不安=金融広告の最大テーマ
- **到達PV前提**: 公式ねんきんネットはログイン障壁が高く「ざっくり試算」に空白。年収×加入年数ページ量産
- **リスク**: YMYL・制度改定。概算であることの明示必須
- **立ち上げ**: 8〜12ヶ月 / **作りやすさ**: ○2〜3日

### 7. 履歴書/職務経歴書PDF — Low ¥0.5万 / **Base ¥2.2万** / High ¥10万
- **ボリューム根拠**: 「履歴書 テンプレート/pdf/作成」で10万規模の恒常需要
- **なぜCPC高い**: 転職エージェント（CPC 150〜400円）。求職者ど真ん中
- **到達PV前提**: ツール＋「職種別 例文」記事群。**道具型=AI Overview控除ほぼ無し**が効く
- **リスク**: 競合多。「登録不要・ローカル完結・AI下書き貼り付け→JIS整形」で差別化
- **立ち上げ**: 6〜10ヶ月 / **作りやすさ**: ○3日（PDF+CJK資産直撃）

### 8. フリーランス税金・国保・手取りシミュ 🆕 — Low ¥0.4万 / **Base ¥2.0万** / High ¥10万
- **ボリューム根拠**: 「個人事業主 手取り」「フリーランス 税金」数万〜10万。副業・独立トレンドで成長
- **なぜCPC高い**: freee/マネーフォワード等会計SaaSの獲得競争が激しい（CPC 200〜600円）
- **到達PV前提**: 売上×経費率×青色控除の組合せページ。#4と部品共有
- **リスク**: インボイス・控除の改定追従
- **立ち上げ**: 6〜10ヶ月 / **作りやすさ**: ○2〜3日

### 9. 相続税・贈与税概算 — Low ¥0.4万 / **Base ¥2.0万** / High ¥10万
- **ボリューム根拠**: 「相続税 計算」数万〜10万。大相続時代で増加基調
- **なぜCPC高い**: 税理士紹介・信託銀行・不動産（CPC 300〜800円）。1案件数十万円の士業広告
- **到達PV前提**: 遺産額×相続人構成ページ＋家系図UIの独自性でCTR 2〜4%
- **リスク**: YMYL最重量級。監修表記・免責を最初から
- **立ち上げ**: 8〜12ヶ月 / **作りやすさ**: ○2〜3日

### 10. 育休・産休給付金計算 🆕 — Low ¥0.4万 / **Base ¥1.8万** / High ¥8万
- **ボリューム根拠**: 「育休 手当 計算」「出産手当金」数万〜10万。制度拡充で検索増
- **なぜCPC高い**: 保険・ベビー用品・転職（CPC 150〜400円）。ライフイベント広告の起点
- **到達PV前提**: #11妊娠週数と相互送客するクラスタで獲得CTR上振れ狙い
- **立ち上げ**: 6〜10ヶ月 / **作りやすさ**: ○2日 / **リスク**: 制度改定追従

### 11. 妊娠週数/出産予定日計算 — Low ¥0.4万 / **Base ¥1.8万** / High ¥8万
- **ボリューム根拠**: 「出産予定日 計算」等で10万規模・出生数減でも検索行動は安定
- **なぜCPC高い**: ベビー用品・学資保険・保険相談（CPC 100〜300円だが**40週再訪でLTV高**）
- **到達PV前提**: 1ユーザー×40週の再訪構造がPVを複利で積む（週ページ40枚）
- **立ち上げ**: 8〜12ヶ月（YMYL・週ページ継続投資） / **作りやすさ**: ◎計算機1日＋継続
- **リスク**: YMYL・医療監修コスト

### 12. 電気・ガス料金プラン比較 — Low ¥0.4万 / **Base ¥1.8万** / High ¥9万
- **ボリューム根拠**: 「電気代 比較」「電力会社 乗り換え」10万規模・料金高騰で追い風
- **なぜCPC高い**: 新電力の乗換獲得競争（CPC 200〜600円）＋アフィ併用可
- **リスク**: **料金表の鮮度維持=運用コスト**が他案より重い。B要
- **立ち上げ**: 8〜12ヶ月 / **作りやすさ**: △2〜3日＋更新運用

### 13. 医療費控除・還付金計算 🆕 — Low ¥0.3万 / **Base ¥1.5万** / High ¥8万
- **根拠**: 確定申告期（2〜3月）に数十万規模へスパイク。会計ソフト広告が同時期に高騰=RPMもスパイク
- **立ち上げ**: 申告期照準で6ヶ月 / **作りやすさ**: ◎1日 / **リスク**: 収益の7割が1〜3月に集中

### 14. iDeCo節税シミュレータ 🆕 — Low ¥0.3万 / **Base ¥1.5万** / High ¥7万
- **根拠**: 「iDeCo シミュレーション」数万・拠出上限引上げで成長。証券広告CPC 300〜800円
- **立ち上げ**: 6〜10ヶ月 / **作りやすさ**: ◎1日（#1と部品共有） / **リスク**: 制度改定

### 15. 住宅ローン借り換えメリット計算 🆕 — Low ¥0.3万 / **Base ¥1.5万** / High ¥8万
- **根拠**: Vol数万と小さいが**借換広告はCPC全案中最高帯（500〜1,500円）**=金利上昇局面で需要・単価とも上振れ
- **立ち上げ**: 8〜12ヶ月 / **作りやすさ**: ◎1日（#3と部品共有） / **リスク**: 金利環境次第でVol変動

## 「高収益×作りやすい」象限

```
            作りやすい(◎1〜2日・client完結)          手がかかる(3日超 or 運用重)
高収益   │ ★複利/NISA ★ふるさと納税 ★住宅ローン    │ 年金シミュ・相続税
(Base    │ ★手取り ★iDeCo ★借換 ★医療費控除       │ 履歴書PDF(3日)・プラン比較(運用)
1.5万+)  │ 退職金失業給付・フリーランス税金          │ 妊娠週数(監修継続)
─────────┼───────────────────────────────────────────┼─────────────────────────────
中低収益 │ 和暦・日付営業日・電子署名・残業代        │ 為替・定期預金比較・仮想通貨損益
         │ 有給・源泉徴収・QR・マイクテスト          │ (データ更新運用が本体)
```

**勝ち筋**: 左上の★群はすべて「お金の計算機」で部品を共有する。**1ドメイン「お金の計算機ポータル」に複利→ふるさと納税→手取り→iDeCo→借換→医療費控除を1週間で6本並べる**のが最短の収益ルート。ドメイン評価も合算で立ち上がる。

**ポートフォリオ視点**: 高CPC1本狙い（借換・カードローン等Vol小×CPC極高）は分散が効かず順位ブレで収益が消える。**Base¥1〜3万の計算機を10〜15本束ねて月15〜30万円**を狙う方が、AI Overview・アルゴリズム更新への耐性も高い。汎用ツール（PDF/QR）は収益でなく**流入とブランドの土台**として持つ。
