## 第1弾（PDF.ai資産直撃＋最速群 — 合計1〜2週間で6本）

### 1. 電子署名・サイン挿入 📄 作れる度125 / 作るべき度75 — **筆頭**
- **なぜ今**: PDF.aiエディタにモード追加するだけ＝全候補中の最短。既存トラフィックの回遊先が即増える
- **勝ち筋**: 「pdf 署名 無料」の巨大KW＋「電子署名の法的効力」解説記事で高CPM面。既存PDF.aiと相互送客
- **使うAI/手順**: Claude/Fableで署名パッド(canvas)→透過PNG→pdf-lib挿入を一括生成→既存エディタにモード統合→実PDF数種で配置検証
- **MVP範囲**: 手書きパッド＋画像アップの2方式・ドラッグ配置・DL。日付/テキストスタンプは第2次
- **日数**: **0.5〜1日** / **広告動線**: 既存のDL後動線をそのまま＋解説記事面
- **リスク**: DocuSign系との文脈差を明確に（「今すぐ1枚に署名」ライト層特化）

### 2. 履歴書/職務経歴書PDF 📄 80/80
- **なぜ今**: 転職広告=最高CPM帯×巨大KW×「AI下書き→JIS様式」受け皿ポジションはAI時代に強くなる一方
- **勝ち筋**: ツール本体＋「職種別 職務経歴書 例文」記事量産。和暦早見(#3)・証明写真から送客
- **使うAI/手順**: FableでJIS様式フォーム→pdf-lib+Noto CJK差し込みを一括生成→印刷崩れ検証→例文記事はAI下書き+人監修
- **MVP範囲**: JIS履歴書1様式＋localStorage下書き保存。職務経歴書・写真整形は第2次
- **日数**: **3日** / **広告動線**: 転職系広告を入力完了→DL画面に。DL後入口復帰はPDF.aiパターン流用
- **リスク**: 競合C4。「登録不要・個人情報を渡さない」ローカル完結訴求で正面回避

### 3. 和暦⇄西暦・年齢早見 75/120
- **なぜ今**: 競合弱(C2)×実装最軽量×履歴書クラスタの入口。ロングテール量産型の教科書案件
- **勝ち筋**: 「昭和◯年 西暦」「平成◯年 何歳」の年別静的ページ数百枚をAIで一括生成しロングテール総取り
- **使うAI/手順**: Fableで変換ロジック＋年別ページテンプレ＋静的生成(Astro等)を一括→記入例だけ人が監修
- **MVP範囲**: 変換UI＋履歴書用早見（満年齢・入学卒業年度）＋年別ページ生成
- **日数**: **0.5〜1日** / **広告動線**: 転職・資格系。#2履歴書への送客が本命
- **リスク**: AI直答(AI Overview)に吸われる→ブックマーク性と回遊で1訪問価値を上げる

### 4. 日付・営業日計算 75/75
- **なぜ今**: #3と同一ドメイン・同一部品で「日付の道具箱」化。祝日込み計算はAI誤答頻発=検証需要が残る
- **勝ち筋**: 「日数 計算」「営業日 計算」の巨大KW＋祝日・連休一覧ページの年次スパイク
- **使うAI/手順**: Fableで祝日JSON＋日付演算＋プリセットUI一括生成。祝日データ年1回確認のみ人
- **MVP範囲**: 日数差・◯営業日後・期限逆算＋今年来年の連休一覧
- **日数**: **1日** / **広告動線**: ビジネス実務層向け汎用＋#3と回遊
- **リスク**: 競合中堅あり→営業日・期限逆算の実務特化で差別化

### 5. マイク/カメラ/スピーカーテスト 50/120
- **なぜ今**: 競合空白(C2)×AI会議時代に増える需要×物理接地でAI耐性最強クラス
- **勝ち筋**: 「マイク テスト」即時KW＋「Zoom/Meet/Teams×症状別」対処記事マトリクスで面
- **使うAI/手順**: FableでgetUserMedia音量メータ・カメラプレビュー・テスト音を一括生成→実機/ブラウザ互換確認だけ人
- **MVP範囲**: マイク音量メータ・カメラプレビュー・スピーカーLR テスト音の3点
- **日数**: **1日** / **広告動線**: 会議ツール・ヘッドセット系ガジェット広告。平日午前の緊急文脈
- **リスク**: コピーされやすい単機能→対処法記事の面の厚さで防衛

### 6. 隠しUnicode・AI痕跡クリーナー 50/90
- **なぜ今**: 競合空白×0.5日で出せる最軽量×AI利用増で需要成長中。SNS拡散性もある
- **勝ち筋**: 「ゼロ幅スペース 削除」等の空白KW＋「AI出力の見えない文字」解説のバズ文脈
- **使うAI/手順**: FableでUnicodeカテゴリ検出＋可視化＋正規化を一括生成（検出リストの網羅レビューだけ人）
- **MVP範囲**: 貼り付け→不可視文字ハイライト→ワンタップ除去・スマート引用符正規化
- **日数**: **0.5日** / **広告動線**: 開発者・ライター向け汎用ツール広告
- **リスク**: エディタ標準機能化→社内文書ルール正規化プリセットで深掘り

### 7. 複利/NISA積立シミュレータ 75/133 — **第2弾筆頭**
- **なぜ今**: 両分析通算の最高評価。高CPM(金融)×client完結×AI耐性最強で「作るべき度」全体2位
- **勝ち筋**: 「月◯万×△年」組合せ静的ページでロングテール＋取り崩し(FIRE)一気通貫は競合が薄い
- **使うAI/手順**: Fableで計算＋グラフ＋シナリオ比較UIを一括生成→金融免責文言と検証だけ人
- **MVP範囲**: 積立額/利回り/期間→推移グラフ＋取り崩しモード。1画面
- **日数**: **1日** / **広告動線**: 証券・ロボアド系高単価。結果画面下＋解説記事面
- **リスク**: 金融公式がSEO上位→ロングテールKWと試算URL保存等の道具価値で刺す

### 8. 住宅ローン計算機 75/94
- **なぜ今**: #7と部品共有で2本目は更に速い。最高CPM帯・巨大KW
- **勝ち筋**: 「借入額×金利×年数」静的ページ＋変動vs固定・繰上・ペアローンのシナリオ記事
- **使うAI/手順**: Fableで償還計算＋比較グラフ一括生成→銀行公式と計算突合だけ人
- **MVP範囲**: 月々・総支払・繰上返済比較 / **日数**: **1日**
- **広告動線**: 不動産・借り換え系最高CPM / **リスク**: 競合C4→中立比較・登録不要で割込み

### 9. 収入印紙・印紙税判定 37.5/120
- **なぜ今**: 競合空白(C2)×法定額の一意判定＝AI耐性最強×BtoB高CPM。コードは1日、検証に1〜2日だけ投資
- **勝ち筋**: 国税庁の読みにくい表を判定UI化＋文書種類×金額帯の判定ページ量産
- **使うAI/手順**: Fableで判定UI＋ページ生成→**税額表の国税庁一次資料突合を人が必ず実施**
- **MVP範囲**: 文書種類＋金額→印紙額・電子契約なら不要判定 / **日数**: **2〜3日**（検証込み）
- **広告動線**: 電子契約SaaS・会計ソフトBtoB / **リスク**: 転記ミス=信頼失墜。検証工程を削らない

### 10. 妊娠週数/出産予定日計算 75/80
- **なぜ今**: 1ユーザー40週再訪の構造×ベビー・保険の安定高CPM。計算機は1日で出る
- **勝ち筋**: 計算機→「妊娠◯週」40ページの週次解説で再訪とロングテール同時取り
- **使うAI/手順**: Fableで計算機一括生成→週ページはAI下書き+**医療監修を段階投入**（YMYL）
- **MVP範囲**: 予定日・今日で何週何日＋直近数週の解説から段階リリース / **日数**: **計算機1日＋週ページ継続**
- **広告動線**: ベビー用品・学資保険系 / **リスク**: YMYLのSEO難度→監修表記・出典明示を最初から
