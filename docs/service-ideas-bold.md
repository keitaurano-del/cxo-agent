## カテゴリ1: 気まずさの外注 — 催促・お詫び・お断りの感情労働を仕組みが引き受ける

### B-01 カエシテ係
**魔法:** お金・モノの督促の「主語」を人からシステムに移す。
貸した3,000円、貸したままの傘。今は「言えずに関係が濁る」か「言って気まずくなる」の二択(before)。貸し借りを共有リンクで登録しておくと、期日が来たら**サービスが中立の顔で両者に**「そろそろ精算の時期です」と通知する。催促したのはアプリであって私じゃない——この言い訳の余地こそが商品(after)。
なぜ無い: 割り勘計算・送金請求はあるが、生々しい請求通知は逆に角が立つ。「気まずさの緩衝材」自体を製品化した例は弱い。なぜ今: 送金アプリ普及で「精算の最後の一歩」だけが残った。
刺さる人: 飲み会の立替常習の幹事、ルームシェア、ママ友間の立替。広がり: 貸し借り登録には相手を招待する＝1利用1招待の構造。需要H(誰もが年数回刺さる) / 収益: 広告+送金アフィ / 大胆さM

### B-02 おことわり残高
**魔法:** 「断る」を文面生成でなく**在庫管理**として扱う。
誘いを断るたび記録すると「この人には3連続で断っている」「そろそろ一度乗らないと切れる糸」が残高として見える(before: 断った履歴は記憶任せで、気づいたら疎遠)。文面提案はおまけで、本体は**関係の摩耗メーター**と「次はこちらから誘う」リカバリ提案(after)。
なぜ無い: 断り例文サイトはあるが「断りの累積が関係を壊す」という時間軸を扱った製品が無い。なぜ今: 誘いがテキスト化(LINE)され、断りもログに残る時代になった。
刺さる人: 誘われがちだが体力のない社会人、育児で誘いを断り続けている人。広がり: 「断り方」検索から流入→残高機能で定着。需要M(概念の教育が要る) / 収益: 広告 / 大胆さH

幹事が未納者に個別凸する地獄(before)→集金ページを作ると、未納が誰かは幹事にだけ見え、**督促は奉行(仕組み)が段階的に**行う。払った人には即座に「済」が立ち、幹事は一度も嫌われない(after)。
なぜ無い: 集金アプリは送金効率の文脈で作られ、「幹事の心理的負担」を主役にした設計が無い。なぜ今: QR送金の普及で回収手段は揃い、残ったのは督促の気まずさだけ。
刺さる人: PTA会計、少年野球の会計係、ゼミ幹事。広がり: 集金1件=参加者全員がURLを踏む。需要H / 収益: 広告、将来は決済手数料 / 大胆さM

## カテゴリ2: 「言った言わない」を消す — 記録・記憶の外部化

### B-08 約束手形
**魔法:** 口約束をその場で10秒で「双方承認つきの軽い記録」にする。
「今度おごるよ」「ゲームは1日1時間ね」「来月までにやる」——言った言わないで揉める(before)。スマホを見せ合ってワンタップ、**両者が押した軽い約束**として残り、期日には両方に通知。法的契約の重さゼロ、でも記憶より強い(after)。
なぜ無い: 契約書は重すぎ、メモは一方的。「二者間の軽い合意」というちょうど良い重さの器が無かった。なぜ今: 揉め事の大半がテキスト化されており「軽い証拠」への心理的抵抗が下がった。
刺さる人: 子どもとルールを決める親、友人間の貸し借り、フリーランスの口頭合意。広がり: 約束は常に2人以上＝招待内蔵。需要M(習慣化が壁) / 収益: 広告 / 大胆さH

### B-09 モノの戸籍
**魔法:** 家中のモノに「戸籍」を持たせ、購入〜保証〜修理〜処分までの生涯を1箇所に。
保証書はどこ、型番なに、フィルター交換いつ買った(before)→レシートと型番を撮るだけで戸籍登録。**壊れた瞬間に「保証残り3ヶ月・修理窓口・型番」が3秒で出る**(after)。処分時は捨て方・売り時まで。
なぜ無い: 家財管理アプリは入力が重くて全滅してきた。撮るだけで型番・購入日が入る精度が無かった。なぜ今: 画像からの型番読取・レシート解析が実用域。
刺さる人: 新築・引越し直後の家庭、フリマ常用者。広がり: 「保証書 なくした」等の駆け込み検索から。需要H(困る瞬間が万人に来る) / 収益: 修理・買替アフィ+広告 / 大胆さM

### B-10 家の取扱説明書
**魔法:** ゴミの日・ブレーカー・水道の元栓・かかりつけ医・Wi-Fi——「家の運用知識」を1冊にして権限つきで共有。
その知識が全部お母さんの頭の中にだけある(before)。入院・出張・帰省で家が回らなくなる。1冊にしておけば、**留守番の家族・ベビーシッター・帰省中の祖父母に必要ページだけ**渡せる(after)。
なぜ無い: 家族アプリは予定・写真共有に寄り、家の「運用ドキュメント」という発想が無い。なぜ今: 共働きで「家事の属人化」が本当に痛くなり、シッター・家事代行など第三者に渡す需要も生まれた。
刺さる人: ワンオペ側の親(自分が倒れたら詰む自覚がある)、二拠点生活者。広がり: 出産入院前・単身赴任前の準備記事から。需要M / 収益: 広告、家事代行送客 / 大胆さM

### B-11 復唱くん
**魔法:** 口頭指示を「こう理解しました」の確認テキストに変えて相手に返す、認識合わせの儀式。
上司の口頭指示、義母の頼まれごと。やってから「そうじゃない」(before)→聞いた直後に要点を吹き込むと**確認文が生成され、相手に「この理解で合ってます?」と送れる**。相手がOKを押した記録も残る(after)。
なぜ無い: 議事録ツールは会議用で、日常の1対1の指示には大げさ。「復唱」という軽い単位の製品が無い。なぜ今: 音声→要点化が一瞬になった。
刺さる人: 指示が曖昧な上司を持つ若手、建設・介護など口頭文化の現場。広がり: 職場で1人使うと相手側も知る構造。需要M / 収益: 広告→チーム版 / 大胆さM

### B-12 もしもの引き継ぎ書

刺さる人: 家計を握っている側の配偶者、独身の一人っ子。広がり: 防災の日・大病報道のたびに想起される。需要M(先送りされがち) / 収益: 保険・士業送客+広告 / 大胆さM

### B-13 診察前メモ

なぜ無い: 健康記録アプリは網羅型で重い。「診察という3分間のための準備」に特化した軽さが無かった。なぜ今: 雑多なメモを医療文脈の時系列に整えるのはAIの独壇場(裏方に徹する)。
刺さる人: 子の体調を説明する親、高齢の親に付き添う子、婦人科など言語化が難しい受診。広がり: 「症状 伝え方」検索+小児科の待合の口コミ。需要H / 収益: 広告、オンライン診療送客 / 大胆さM

### B-14 わが家の語録

なぜ無い: 日程調整ツールは「集める」までを作り、「決める」の責任は幹事に残してきた。決定の代行こそが本丸なのに。なぜ今: 「AIが決めたなら仕方ない」という決定権の外部化が心理的に受容されつつある。

なぜ無い: カレンダー共有は「相手に開示させる」重さで友人関係では成立しない。「推測でいいから配慮したい」という需要は誰も製品にしていない。なぜ今: 職業・季節の負荷パターンの推定はAIらしい曖昧タスク。
刺さる人: 気遣いで疲れる誘い手。広がり: 「配慮できる人」になれた体験談。需要L〜M(仮説度高) / 収益: 広告 / 大胆さH

### B-61 家庭内アナウンス室
**魔法:** 家族への連絡(「今日は塾弁いる」「19時に駅まで」)を、各人に届く形・タイミングに変換して配信する。
家族LINEに流しても読まれない、口頭は忘れられる(before)→アナウンス室に投げ込むと、**夫にはカレンダー登録、中学生には夕方の通知、祖母には電話口調のメッセージ**と、相手ごとに最適な形で届き、既読/未達が見える(after)。
なぜ無い: 家族連絡はLINE一択になったが「全員同じ形式で流れて消える」欠陥は放置。個人別の変換・配信は不可能だった。なぜ今: 形式変換・タイミング最適化はAI裏方の得意技。
刺さる人: 家庭の連絡ハブにされている人。広がり: 世帯単位導入が前提。需要M / 収益: 広告 / 大胆さH

### B-62 初めての街コンシェルジュ
**魔法:** 引越し直後の3ヶ月、「この街での正解」を毎週1枚ずつ配るオンボーディング。
病院はどこがいい、ゴミは何時まで、美味いパン屋は——住民なら常識の情報ゼロで新生活が始まる(before)→住所を登録すると、**「1週目: ゴミと防災」「3週目: かかりつけ医の候補3つ」**と街の取扱説明書が段階配信される(after)。先輩住民の一言(B-29連携)も載る。
なぜ無い: 地域情報サイトは網羅羅列で「新住民の時系列ニーズ」に沿っていない。なぜ今: 公開情報の束ね直しと段階配信の設計がAIで安価。
刺さる人: 単身赴任・進学・結婚での転入者(年数百万人)。広がり: 引越し手続き(B-23)からの動線。需要M / 収益: 地域店舗・不動産広告 / 大胆さM
