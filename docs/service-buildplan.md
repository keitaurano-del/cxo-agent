## 0. スコア定義（2軸）

```
作れる度 (Buildability) = AI構築容易性 × スピード × 資産流用 ÷ 技術リスク   ※各1〜5
作るべき度 (Should-build) = 検索需要 × 広告適性 × AI耐性 × 差別化余地 ÷ 競合   ※各1〜5
```

- **AI構築容易性**: 5=Claude/Fableに丸投げでほぼ完成 / 3=AIが書けるが人の検証・データ整備が要る / 1=AIでは書けない中核あり
- **スピード**: 5=0.5〜1日 / 4=2〜3日 / 3=3〜5日 / 2=1週間 / 1=1週間+
- **資産流用**: 5=PDF.ai資産（pdf-lib+fontkit+CJK・エディタUI・D&D・DL後広告動線）直撃 / 3=UI・広告動線など汎用資産のみ / 2=ほぼ新規
- **技術リスク**: 1=静的ロジックのみ / 2=データ正確性・更新運用の責務 / 3=品質保証・法的責任が重い
- 判定線: **作れる度 ≥35 = 「作れる」 / 作るべき度 ≥75 = 「作るべき」**（選抜30件の分布中央値ベース）

#### 1. 複利/NISA積立シミュレータ

**① 検索・流入**
- KW例: 「複利 計算」「積立 シミュレーション」「NISA いくらになる」「FIRE 取り崩し 計算」「月3万 積立 20年」— 情報型→取引型の中間
- 流入形: エバーグリーン（年始・新年度に小スパイク）。ボリューム **H**
- チャネル: SEOオーガニック中心＋ブックマーク再訪（試算は繰り返す）
- 面の取り方: 「月◯万円×△年」「利回り◯%」の組合せ静的ページ量産でロングテール吸収。取り崩し(FIRE)・インフレ調整・ジュニアNISA等のモード別LPで面を厚く

**② AI構築可否とスピード**
- **可**。複利計算・グラフ描画は完全に決定論＝AIが最も得意な領域
- スタック: React+Chart.js（or 軽量SVG自作）・client完結・バックエンド不要
- AI使い分け: Claude/Fableに計算ロジック+UI+グラフを一括スキャフォールド（丸投げ可）。人が詰めるのは金融商品の前提説明・免責文言・SEO記事のみ。推論API不要（原価ゼロ）
- MVP: **1日**（1画面：積立額/利回り/期間→推移グラフ+取り崩しモード）。ボトルネック=グラフUXの磨き込みとSEO記事群の執筆
- 資産流用: 3（PDF.aiのUI部品・広告動線設計・DL後復帰パターン。PDF基盤は不要）

**③ AI時代の機能必要性**
- 残る理由: 決定論＋即時性。スライダー連動の探索的試算は会話UIで構造的に再現不能
- 食われるリスク: AIチャットが埋め込みグラフを返す未来。回避=「保存できる試算URL」「複数シナリオ比較」など道具側にしかない状態管理で防衛
