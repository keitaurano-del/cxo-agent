## A. 方法論・スコアリング基準

### 中核の問い
各案は必ず **「なぜChatGPT等のAIチャットに食われないか / AI時代にこそ効くか」** の理由を明示する。
AI耐性の9軸（案内の (軸n) 表記はこれを指す）:

1. **即時ユーティリティ** — AIに聞くより1クリックが速い。会話コストゼロが価値
2. **決定論・検証可能** — 答えが1つに定まり、AIの"それっぽい嘘"が許されない
3. **ローカル処理・プライバシー** — ファイルを外（LLM含む）に出したくない
4. **成果物生成** — 入力から規格に沿った"書類/作品"が出る。AIは下書き、出力は道具
5. **リアルタイム・一次情報** — 学習データに無い今の値
6. **法的効力・規格・コンプラ** — 様式・署名・提出規格など「正しさの担保」
7. **物理・センサー・デバイス連携** — カメラ/マイク/印刷などハードに接地
8. **AI周辺の新需要** — AI生成物の検証・整形・管理など"AIの周りで発生する仕事"
9. **信頼・審美・一貫性** — 人が最終確定させたい工程

**外した案の基準**: 生成・要約・翻訳・命名そのものが主機能でChatGPT一言で足りるもの。AI推論原価が主役で広告収益で賄えないもの。

### スコア式（前回式に「AI耐性」係数を追加した拡張版）
```
優先度スコア = AI耐性(R) × 検索需要(D) × 作りやすさ(E) × 広告適性(A) ÷ 競合強度(C)   ※各1〜5
```
- **R**: 5=構造的に代替不能（決定論/法規格/ローカル/デバイス） / 3=部分的にAIでも可 / 1=AIチャットで足りる
- **D**: 5=巨大KW群(需要H) / 4=大きめ(H) / 3=中規模(M) / 2以下=ニッチ(L)
- **E**: 5=client完結・数日 / 4=client+軽い工夫 / 3=軽backend or wasm重め / 2以下=重インフラ・データ整備重
- **A**: 5=高CPM(金融/法律/BtoB)＋滞在長 / 3=汎用ツールCPM / 2以下=低CPM
- **C**: 5=巨人多数(逆風) / 3=中堅多数 / 1=空白
- 目安: **100以上=最有望 / 60〜100=有望 / 35〜60=条件付き / 35未満=見送り寄り**（前回式×Rでスケールが変わった点に注意）

### 凡例
- 実装: `C`=client完結 / `B`=軽バックエンド / `AI`=LLM/ML要（数字はE値）
- ★前回#nn = 前回100選と重複（AI耐性の観点で改めて有望な理由をAI耐性列に記載）
- 🆕 = 新規、うち「AI時代ならでは」案はカテゴリ7に集約＋各所に散在
